# Amazon-Sales-Dashboard-Analysis-2024-using-Excel
To analyse and visualize Amazon sales data across Indian cities and states, enabling insights into regional performance, product category trends, and sales goal tracking. The dashboard supports business decisions by identifying high-performing territories and product lines.
<pre>
Tools & Technologies Used:
o Microsoft Excel.
o Pivot Tables.
o Bar, Column, and Pie Charts.
o Named Ranges & Slicers.
o Conditional Formatting.

Dataset Overview: <a href="Amazon-Sales-Dashboard-Analysis.png">Data Set</a>
o Source: Simulated Amazon sales data.
o Size: 300+ cities across 20+ states.
o Fields: City, State, Product Category, Sales Amount (₹), Units Sold.

Workflow Summary: <a href="Territorial Tracker FY-2024.png">Calculations</a>
o Cleaned and structured raw data.
o Aggregated sales and units sold by city, state, and category.
o Built pivot tables for dynamic filtering.
o Designed dashboard layout with slicers and labelled visuals.
o Created performance tracker for target vs. achieved metrics

Key Dashboard Features: <a href="Visualizations Overview – Amazon Sales Dashboard 2024.png">Visualization</a>
o City-wise Sales Performance.
o State-wise Sales Analysis.
o Product Category Breakdown.
o Progress Tracker (Achieved vs Target).
o Territorial Sales Overview.
o Completion Percentage Display.

Insights & Results: <a href="Project 01.xlsx">Final outcome</a>
o	Top States: Uttar Pradesh, Rajasthan, Tamil Nadu.
o	Top Cities: Varanasi, Jaipur, Dehradun.
o	Best-Selling Categories: Electronics, Furniture, Toys.
o	Progress Achieved: ₹9M+ sales against ₹12.5M target (~72% completion).
 </pre>
